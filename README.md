
# 🛍️ Cahely Modas — Sistema de Gestão
<img width="1891" height="883" alt="image" src="https://github.com/user-attachments/assets/194ea599-5be1-42f0-8c63-281e0bf6b82e" />


Sistema web desenvolvido para apoiar a gestão de uma loja de roupas consignadas, reunindo controle de fornecedores, estoque, vendas e acompanhamento financeiro em uma única aplicação.

O projeto nasceu a partir de uma atividade acadêmica e foi evoluído para atender a uma necessidade real do dia a dia da loja Cahely Modas.

## 🎯 Objetivo

Desenvolver uma solução simples e funcional para organizar as operações da loja, facilitar o acompanhamento das movimentações e oferecer uma visão geral dos resultados financeiros.

## ✨ Funcionalidades

- 📊 Dashboard com indicadores de vendas, estoque e financeiro.
- 👥 Cadastro e gerenciamento de fornecedores.
- 👕 Controle de entrada de peças consignadas.
- 🛍️ Registro e histórico de vendas.
- 💰 Controle de pagamentos e acertos com fornecedores.
- 📉 Registro e acompanhamento de despesas.
- 📋 Relatórios e exportação de dados.
- 💾 Exportação de backup.
- ✏️ Edição e exclusão de registros com validações para preservar a integridade dos dados.

## 🧰 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🏗️ Arquitetura e funcionamento

A aplicação funciona diretamente no navegador, utilizando JavaScript para as regras de negócio e LocalStorage para persistência dos dados.

Não utiliza atualmente um banco de dados em nuvem ou backend.
